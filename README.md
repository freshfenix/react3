# React у дії — навчальна лабораторія

Невеликий навчальний проєкт на **React**, **TypeScript** і **Vite**. Сторінка демонструє керування станом, повторне використання компонентів, два підходи до форм і завантаження даних із зовнішнього API. Інтерфейс і пояснення створені українською мовою.

## Чого навчає проєкт

- Зберігати та оновлювати стан компонента за допомогою `useState`.
- Передавати текст, обробники подій і стилі через типізовані `props`.
- Будувати контрольовані й неконтрольовані форми.
- Використовувати `useRef` для читання значень DOM-елементів.
- Виконувати асинхронний запит у `useEffect` і відображати стани завантаження.
- Описувати props, події, refs і відповіді API типами TypeScript.
- Створювати адаптивний інтерфейс за допомогою CSS.

## Можливості

### Керування кольорами

Три кнопки циклічно перемикають фон сторінки, колір тексту та колір кнопок. Значення зберігаються в стані компонента `App`. Для кнопок використовується спільний компонент `Button`, якому батьківський компонент передає текст, обробник кліку та стилі через props.

### Контрольована форма

У `ControlledForm` значення текстового поля, списку вибору й прапорця зберігаються в React через `useState`. Поля оновлюють стан під час введення, а після надсилання показується підсумок.

### Неконтрольована форма

У `UncontrolledForm` значення полів не зберігаються в стані під час введення. Компонент отримує доступ до полів через `useRef` і зчитує їх під час надсилання форми. Кнопка очищення скидає поля та результат.

### Дані з API

`PostsPanel` завантажує п’ять дописів із [JSONPlaceholder](https://jsonplaceholder.typicode.com/posts?_limit=5) під час монтування компонента. Інтерфейс окремо показує стани завантаження, успіху й помилки. Запит можна повторити; `AbortController` скасовує його під час очищення ефекту.

> Для відображення дописів потрібне підключення до інтернету. API є зовнішнім навчальним сервісом, окремий сервер проєкту не налаштовується.

## Технології

- React 19

- CSS

## Запуск проєкту

Потрібні встановлені Node.js і npm. У терміналі перейдіть до папки проєкту, встановіть залежності та запустіть сервер розробки:

```bash
npm install
npm run dev
```

Відкрийте локальну адресу, яку Vite покаже в терміналі (зазвичай <http://localhost:5173/>).

## Команди

| Команда | Призначення |
| --- | --- |
| `npm run dev` | Запустити сервер розробки з гарячим оновленням сторінки (HMR) |
| `npm run typecheck` | Перевірити типи TypeScript без створення файлів збірки |
| `npm run lint` | Перевірити код за правилами ESLint |
| `npm run build` | Перевірити типи й створити production-збірку в `dist/` |
| `npm run preview` | Переглянути створену production-збірку локально |

## Як організовано код

- `src/main.tsx` — створює React-корінь і рендерить `App` у режимі `StrictMode`.
- `src/App.tsx` — головна сторінка, стани палітри та компонування навчальних прикладів.
- `src/components/Button.tsx` — повторно використовувана кнопка з типізованими props.
- `src/components/ControlledForm.tsx` — контрольована форма на `useState`.
- `src/components/UncontrolledForm.tsx` — неконтрольована форма на `useRef`.
- `src/components/PostsPanel.tsx` — запит до API та стани його виконання.
- `src/App.css` і `src/index.css` — стилі сторінки та глобальні стилі.
- `tsconfig.json` — налаштування TypeScript, зокрема строгий режим перевірки типів.

## Навчальні нотатки

- У контрольованому полі React є джерелом актуального значення: для текстового поля використовуються `value` та `onChange`, для прапорця — `checked` та `onChange`.
- У неконтрольованому полі браузер зберігає введене значення, а `ref.current` дає змогу прочитати його, коли це потрібно.
- `useEffect` запускає запит після монтування. Функція очищення скасовує запит під час розмонтування або повторного запуску ефекту.
- `npm run build` спочатку запускає перевірку TypeScript (`tsc --noEmit`), а потім збирає застосунок через Vite.
